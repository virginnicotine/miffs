# My Fault Is Your Salvation — сайт новеллы

Статичный сайт: никаких сборщиков и установок. Открывается просто как `index.html`.

## Структура

```
index.html   — тексты, ссылки, структура страницы
style.css    — цвета, шрифты, анимации
script.js    — заставка, музыка, звуки, курсор, звёзды, окно ошибки
assets/      — музыка, аватарки, арты галереи
```

## Как выложить на GitHub Pages

1. Создай репозиторий на GitHub и загрузи в него **все файлы из папки** (не саму папку): `index.html`, `style.css`, `script.js`, `README.md`, `assets/`.
2. Settings → Pages → Source: `Deploy from a branch` → ветка `main`, папка `/ (root)` → Save.
3. Через 1–2 минуты сайт откроется по адресу `https://ТВОЙ-НИК.github.io/НАЗВАНИЕ-РЕПО/`.

Чтобы проверить локально, достаточно открыть `index.html` в браузере.

### Тексты (`index.html`)
- Описание новеллы — внутри `<section id="hero">`, два тега `<p>`.
- Страницы дневника — `<section id="excerpts">`, один `<article class="page ...">` = одна страница. Перенос строки: `<br>`.
- Зачёркивающееся слово: оберни его в `<span class="x" style="--sd:1s">слово</span>`. `--sd` — задержка анимации, чтобы слова не зачёркивались одновременно.
- Авторы — `<section id="authors">`: ник (`<h3>`), роль (`class="role"`), текст (`<p>`).
- Платформы — `<div class="plat">`.
- Кредит трека — в плеере (`<div class="player ...">`) и в футере.

### Галерея (`index.html`, `<div class="track">`)
Одна карточка = один `<div class="card glass ...">`. Чтобы заменить арт, положи файл в `assets/` и поменяй `src=`. Чтобы добавить арт, скопируй целую карточку. Название и описание — в `<h4>` и `<p>`.
Особые карточки: `mom` (помехи и окно «Доступ запрещён») и `him` (медленный наезд на лицо). Это классы после `card glass`.

### Окно ошибки (карточка `mom`)
Текст — `<div id="err">` в `index.html`. Чтобы убрать помехи, удали класс `mom` у карточки.

### Музыка и заставка (`script.js`, начало блока «entry + music»)
```js
var SRC='assets/music.mp3', OFF=8, LEN=8.95
```
- `SRC` — файл с музыкой.
- `OFF` — с какой секунды трека начать (8 = пропустить первые 8 с).
- `LEN` — через сколько секунд после клика включится белая вспышка. Дроп сейчас на 17,5 с трека. Если вспышка опаздывает — **уменьши** `LEN` (например, 8.7), если спешит — увеличь.
Другая песня: положи файл в `assets/`, поменяй `SRC`, затем найди дроп и пересчитай `LEN = (секунда дропа) − OFF − 0.25`.

### Слоган на заставке
- Текст на экране входа — `<blockquote>` в `index.html`.
- Что печатается и где «ошибка» — массив `ops` в функции `typeIt()` в `script.js`: `'t'` печатать, `'e'` стереть N символов, `'p'` пауза (мс). Скорость печати — `110+Math.random()*80`.

### Цвета и шрифты (`style.css`, самый верх, `:root`)
```css
--ink:#030923; --navy:#041A53; --blue:#0059FF; --white:#fff;
```
Шрифты (Cormorant Garamond, Inter, Marck Script) подключены ссылкой в `<head>` `index.html`.

### Звёзды, луна, пыль
- Количество звёзд в шапке — `j<320` в `script.js`; блики — `k<42`; пыль по сайту — `i<170`.
- Луна — класс `.moon` в `style.css` (позиция `right`, `top`, размер `width`).
